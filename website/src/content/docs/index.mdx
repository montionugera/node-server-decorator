## Multi-Language at a Glance

Switch your language once below, and all synced code samples across the entire documentation site switch together:

<Tabs syncKey="lang">
  <TabItem label="TypeScript / Node" icon="seti:typescript">
```typescript
import { cache, EmitOnSuccess, tracking } from '@montionugera/server-decorator';

export class UserService {
  @cache({ ttl: 60 })
  @tracking()
  async getUser(id: string) {
    return db.users.findById(id);
  }

  @EmitOnSuccess({ topic: 'user.created' })
  async createUser(payload: CreateUserDTO) {
    return db.users.create(payload);
  }
}
```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
```python
from server_decorator import cache, emit_on_success, tracking

class UserService:
    @cache(ttl=60)
    @tracking()
    async def get_user(self, id: str):
        return await db.users.find_by_id(id)

    @emit_on_success(topic="user.created")
    async def create_user(self, payload: CreateUserDTO):
        return await db.users.create(payload)
```

## Core Pillars

<CardGrid stagger>
  <Card title="Wire-Contract Driven" icon="seti:json">
    Contracts and JSON schemas in `contracts/` serve as the absolute source of truth. All runtimes validate against the same golden fixtures.
  </Card>
  <Card title="Byte-Identical Parity" icon="approve-check-circle">
    EntitySpec IR and OpenAPI 3.1 documents generated by Node, Python, Go, and Nim are byte-for-byte identical, strictly asserted in CI.
  </Card>
  <Card title="Multi-Replica Safe" icon="random">
    Canonical cache key algorithms and explicit UTC offset formatting prevent subtle cross-runtime and multi-region cache poison bugs.
  </Card>
  <Card title="Lockstep Versioning" icon="rocket">
    All language libraries publish simultaneously under a single semver tag, ensuring seamless polyglot microservice compatibility.
  </Card>
</CardGrid>
