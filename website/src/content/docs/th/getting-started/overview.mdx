# ภาพรวมของ server-decorator

**server-decorator** ถูกสร้างขึ้นเพื่อแก้ไขปัญหาสำคัญในสถาปัตยกรรม Microservices ที่ใช้หลายภาษาโปรแกรม (Polyglot): **การทำให้พฤติกรรมระหว่างภาษาทำงานตรงกันอย่างสมบูรณ์แบบ**

ในระบบที่ประกอบด้วยหลายภาษา เช่น API Gateway เขียนด้วย TypeScript สื่อสารกับ Worker ที่เขียนด้วย Python หรือ Go บ่อยครั้งที่การเขียน Decorator หรือโครงสร้างข้อมูลแยกกันจะทำให้เกิดความผิดพลาดเล็กๆ น้อยๆ เช่น:
- โครงสร้าง Cache Key ไม่ตรงกัน ทำให้เกิด Cache Miss หรือข้อมูลทับซ้อน
- ซองข้อความในคิว (Message Envelope) มีฟิลด์ไม่ตรงกัน ทำให้ Consumer อ่านข้อมูลล้มเหลว
- กฎการตรวจสอบข้อมูล (Validation DTO) มีพฤติกรรมต่างกันระหว่าง Zod และ Pydantic

`server-decorator` แก้ปัญหานี้โดยใช้ **Contract เป็นหัวใจหลัก** และมีโค้ดของแต่ละภาษาที่ผ่านการทดสอบ Parity ในระดับไบต์ร่วมกันใน repository เดียว
